# Ovenbird site

Site de apresentação do [Ovenbird](https://github.com/diegopn/ovenbird), editor LaTeX nativo para GNOME.

## Idiomas

- Português (Brasil): https://diegopn.github.io/ovenbird-site/
- English: https://diegopn.github.io/ovenbird-site/en/
- Español: https://diegopn.github.io/ovenbird-site/es/

As páginas de idioma compartilham style.css, script.js e os arquivos em assets/images/.

## GitHub Pages

No repositório ovenbird-site, abra **Settings → Pages** e selecione **Deploy from a branch**, branch main e pasta /(root). O site estático não exige build.

O seletor de idioma navega entre páginas independentes. A preferência de tema claro/escuro é salva no navegador.
