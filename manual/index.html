01 · Visão geral

O que é o Ovenbird

O Ovenbird é um aplicativo para Linux e GNOME que reúne a edição de documentos LaTeX e o gerenciamento de uma biblioteca local de referências BibTeX. Os documentos do projeto continuam sendo arquivos comuns, que podem ser abertos e organizados fora do aplicativo.

A biblioteca de referências é mantida no computador e pode ser importada de arquivos BibTeX ou exportada para um arquivo .bib portátil. O aplicativo não exige que a biblioteca esteja vinculada a um projeto específico. A interface está disponível em português do Brasil, inglês e espanhol.

02 · Instalação

Instale a versão 0.1.0

O pacote disponível nesta página é destinado a Linux x86_64 e usa o formato Flatpak. Se o Flatpak ainda não estiver instalado ou configurado no sistema, consulte as instruções de configuração para sua distribuição Linux.

Baixar Ovenbird 0.1.0

  1. Baixe o arquivo Ovenbird-0.1.0-x86_64.flatpak.
  2. Abra o terminal na pasta onde o arquivo foi salvo. Se ele estiver em Downloads, execute:
flatpak install --user "$HOME/Downloads/Ovenbird-0.1.0-x86_64.flatpak"
  1. Confirme a instalação quando o Flatpak solicitar. Depois, procure por Ovenbird no menu de aplicativos do GNOME.
O caminho do comando pressupõe que o arquivo esteja em Downloads. Se você o salvou em outra pasta, substitua o caminho pelo local correto. A primeira compilação pode exigir o download de componentes de suporte do mecanismo LaTeX.

03 · Projetos

Crie ou abra um projeto

Criar projeto

  1. Abra o menu do aplicativo e escolha Novo projeto (New project) (atalho Ctrl+Alt+N).
  2. Escolha um ponto de partida: documento LaTeX em branco ou um dos modelos disponíveis, como ABNT, IEEE, ACM, Elsevier e Springer Nature.
  3. Selecione a pasta onde o projeto será criado, informe um nome e escolha Criar (Create).

O Ovenbird cria uma pasta para o projeto e copia os arquivos do modelo escolhido para ela. Verifique as orientações atuais da instituição ou publicação antes de entregar um documento baseado em um modelo.

Abrir projeto existente

Use Abrir projeto (Open project) no menu do aplicativo (atalho Ctrl+Alt+O) e selecione a pasta do projeto. Para abrir somente um documento, use Abrir documento (Open document) ou Ctrl+O.

04 · Edição

Edite e compile seu documento

Abra um arquivo .tex pela lista de arquivos do projeto. O editor oferece os modos Código (Code) e Visual para trabalhar sobre o mesmo conteúdo LaTeX. Salve o documento para preservar suas alterações.

O modo Visual foi pensado para tarefas comuns e reconhece uma parte dos comandos e ambientes LaTeX. Comandos ou estruturas que ele não reconhece continuam disponíveis como texto-fonte; use o modo Code para revisar ou editar esses trechos diretamente. O modo Visual precisa de um documento com a estrutura básica \begin{document} e \end{document}.

Use o botão Compilar (Compile) na barra superior para gerar o PDF. O aplicativo procura um mecanismo LaTeX disponível; o pacote Flatpak inclui Tectonic. A visualização do resultado aparece na área de PDF quando disponível.

05 · Referências

Organize a biblioteca BibTeX

Abra Referências (References) na navegação lateral para acessar a biblioteca local. Use Adicionar referência (Add reference) para cadastrar uma referência e preencher seus dados bibliográficos. A busca e os filtros ajudam a localizar registros por autor, ano, etiqueta ou tipo.

Para levar referências a um documento, abra o arquivo LaTeX, salve-o e use a ação Inserir citação (Insert citation). As referências usadas pelo projeto podem ser reunidas durante a compilação com os dados da biblioteca local.

Importar e exportar

  • Importar BibTeX (Import BibTeX): escolha um arquivo .bib; as entradas são incorporadas à biblioteca local.
  • Exportar BibTeX (Export BibTeX): escolha onde salvar uma cópia .bib da biblioteca para compartilhar ou usar em outros projetos.

A biblioteca local é independente dos arquivos do projeto. Exporte um arquivo .bib quando quiser manter uma cópia portátil ou transferir suas referências para outro computador.
