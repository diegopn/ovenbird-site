Manual do Ovenbird

Este guia explica os principais fluxos do Ovenbird documentados na versão 0.3.0: instalar o aplicativo, trabalhar em projetos LaTeX, compilar documentos, organizar referências BibTeX e configurar a abertura do aplicativo.

01 · Visão geral

O que é o Ovenbird

O Ovenbird é um aplicativo para Linux com ambiente GNOME que reúne um editor de documentos LaTeX e uma biblioteca local de referências BibTeX. Os arquivos do projeto continuam em formatos comuns, como .tex e .bib, e permanecem na pasta escolhida pela pessoa que os utiliza.

O aplicativo oferece modos Código (Code) e Visual para editar documentos LaTeX. A biblioteca de referências não depende de um projeto específico: é possível cadastrar referências, pesquisar, filtrar, importar arquivos .bib e exportar uma cópia BibTeX.

02 · Instalação

Requisitos e instalação

  • O arquivo publicado é um pacote Flatpak para Linux x86_64.
  • É necessário ter Flatpak instalado e configurado. O pacote usa o runtime org.gnome.Platform versão 51; o arquivo de instalação não inclui esse runtime e o Flatpak pode precisar obtê-lo de uma origem configurada no sistema.
  • A versão Flatpak 0.3.0 inclui Tectonic para compilar documentos. A primeira compilação pode precisar baixar arquivos de suporte do mecanismo LaTeX.

Se o Flatpak ainda não estiver configurado, consulte as instruções para preparar o sistema. A documentação oficial sobre pacotes Flatpak de arquivo único explica a instalação direta e informa que esse tipo de pacote não inclui suas dependências.

Baixar Ovenbird 0.3.0 para Linux x86_64

  1. Baixe o arquivo Ovenbird-0.3.0-x86_64.flatpak.
  2. Se ele estiver na pasta Downloads, abra um terminal e execute:
flatpak install --user "$HOME/Downloads/Ovenbird-0.3.0-x86_64.flatpak"
  1. Confirme a instalação quando solicitado. Depois, abra Ovenbird pelo menu de aplicativos do sistema.

Se o arquivo estiver em outra pasta, substitua o caminho do comando pelo local onde você o salvou. Para abrir pelo terminal após a instalação, use flatpak run io.github.diegopn.ovenbird.

03 · Projetos

Primeira abertura e projetos

Na primeira abertura, o Ovenbird inicia no editor sem um projeto selecionado. Por padrão, nas próximas aberturas ele tenta reabrir o último projeto utilizado. Você pode alterar esse comportamento nas preferências.

Criar um projeto

  1. Escolha Novo projeto (New project) no menu do aplicativo ou use Ctrl+Alt+N.
  2. Selecione um documento em branco ou um dos modelos incluídos: ABNT, IEEE, ACM, Elsevier ou Springer Nature.
  3. Escolha a pasta onde o projeto será criado, informe um nome e confirme em Criar (Create).

O aplicativo prepara uma pasta de projeto com os arquivos do ponto de partida escolhido. Os modelos são uma estrutura inicial; confira as instruções atuais da instituição ou publicação a que o documento se destina.

Abrir um projeto ou documento

Para abrir uma pasta de projeto, use Abrir projeto (Open project) ou Ctrl+Alt+O. Para abrir um único arquivo, escolha Abrir documento (Open document) ou use Ctrl+O.

Preferências de abertura

Abra o menu principal do aplicativo e escolha Preferências (Preferences). Em Abrir ao iniciar, escolha entre o editor LaTeX e a biblioteca de referências. A opção Reabrir o último projeto ao iniciar vem ativada; desative-a se preferir começar sem restaurar o projeto anterior.

As preferências também permitem escolher o tema Automático, Claro ou Escuro e definir a pasta inicial dos diálogos de arquivos. Por padrão, eles começam em Downloads. Use Escolher pasta para selecionar outra pasta ou Redefinir para voltar ao padrão.

04 · Edição

Edite e compile seu documento

Abra um arquivo .tex ou .bib pela lista de arquivos do projeto. Use Ctrl+S para salvar e Ctrl+F para localizar texto no arquivo aberto.

Arquivos .tex: modos Code e Visual

O modo Código (Code) edita a fonte LaTeX; o modo Visual apresenta uma edição formatada do mesmo documento. Para abrir o modo Visual, o arquivo precisa conter \begin{document} e \end{document}. O modo Visual trabalha com um subconjunto dos comandos e ambientes LaTeX implementados pelo aplicativo.

Se um trecho não aparecer no modo Visual, volte ao modo Código para revisar e editar a fonte. O modo Código também é o lugar para trabalhar diretamente com comandos LaTeX que não tenham representação visual.

No editor LaTeX, a barra oferece desfazer e refazer, estilos de parágrafo, negrito, itálico, sublinhado, monoespaçado e inserção de links. Os menus incluem matemática, símbolos, listas e recuos, além de citação. Em Mais opções, ficam inserir imagem ou tabela, comentário LaTeX, nota de rodapé, nota de revisão, rótulo e referência cruzada.

Arquivos .bib: edição BibTeX

Um arquivo .bib do projeto é editado diretamente como texto BibTeX; ele não oferece o modo Visual. Com um arquivo .bib aberto, a ação Adicionar referência bibliográfica (Add bibliographic reference) permite pesquisar a biblioteca local e inserir a entrada escolhida no arquivo aberto. Assim, você pode manter no projeto as entradas que o documento LaTeX usa.

Compilar e ver o PDF

Use Compilar (Compile) ou o atalho Ctrl+Shift+R. O Ovenbird procura latexmk, pdflatex ou Tectonic; a versão Flatpak 0.3.0 inclui Tectonic. Após uma compilação bem-sucedida, o PDF aparece na área de visualização. Consulte o status da compilação para identificar mensagens de erro.

05 · Referências

Organize a biblioteca BibTeX

Abra Referências (References) na navegação lateral para acessar a biblioteca local. Na lista, pesquise os registros e filtre por autor, ano, tag ou tipo. Você também pode ordenar por título, autor, ano ou tag, em ordem crescente ou decrescente.

Adicionar e manter referências

Use Adicionar referência (Add reference) para escolher o tipo de registro e preencher a chave de citação, o título, os autores e a data. Os campos variam conforme o tipo; para um artigo de periódico, por exemplo, o formulário também mostra periódico, volume, número ou edição, páginas, mês, DOI, URL e observação. Depois de salvar, os registros podem ser editados ou removidos pela lista.

As referências podem receber tags. Ao criar ou editar um registro, selecione tags existentes ou crie novas; depois, use o filtro de tags na lista para encontrar os registros correspondentes.

Importar, exportar e inserir citações

  • Importar BibTeX (Import BibTeX): selecione um arquivo .bib; as referências importadas passam a fazer parte da biblioteca local.
  • Exportar BibTeX (Export BibTeX): salve uma cópia .bib das referências da biblioteca.
  • Inserir citação (Insert citation): em um documento LaTeX salvo, use a ação ou Ctrl+Shift+C para pesquisar a biblioteca. Citação insere a chave BibTeX no documento; Referência bibliográfica insere uma referência formatada.

A biblioteca local é independente dos arquivos de cada projeto. Para que uma citação por chave seja encontrada na compilação, a entrada correspondente precisa estar em um arquivo .bib do projeto declarado no documento principal com \bibliography{...} ou \addbibresource{...}. A biblioteca local, por si só, não é incluída automaticamente na compilação. Em um arquivo .bib do projeto aberto no editor, use Adicionar referência bibliográfica para copiar uma entrada da biblioteca local para esse arquivo.

Tags e autores

Em Tags, pesquise pelo nome, ordene a lista e adicione, edite ou remova tags. Elas podem ser usadas para classificar e filtrar registros na biblioteca.

Em Autores, pesquise e ordene por nome completo ou instituição. Cada linha mostra quantas referências estão associadas ao autor; os controles permitem cadastrar, editar ou remover registros de autor. Abra os detalhes para consultar o nome completo, o nome usado nas referências, ORCID, e-mail e instituição.

06 · Dados

Onde ficam os arquivos e como fazer cópias

Os documentos e arquivos de cada projeto ficam na pasta escolhida quando o projeto é criado ou aberto. A biblioteca e as configurações do aplicativo ficam separadas dos arquivos do projeto.

Na instalação Flatpak padrão, os dados locais ficam sob ~/.var/app/io.github.diegopn.ovenbird/data/ovenbird/. Essa pasta contém a biblioteca library.bib e arquivos auxiliares de etiquetas e autores, como tags.json, authors.json e author_profiles.json. As configurações ficam em ~/.var/app/io.github.diegopn.ovenbird/config/ovenbird/settings.json.

Para uma cópia de segurança completa, feche o Ovenbird e copie a pasta inteira do projeto, além das pastas data/ovenbird/ e config/ovenbird/ desses caminhos. Para guardar apenas uma cópia portátil das referências bibliográficas, use Exportar BibTeX e salve o arquivo .bib em outro local.

O Flatpak usa diretórios de dados e configuração próprios para cada aplicativo. Veja a documentação sobre os diretórios XDG no Flatpak.

07 · Solução de problemas

Problemas comuns

O último projeto não pode ser reaberto

Se a pasta do projeto foi movida ou removida, o Ovenbird não consegue restaurá-la ao iniciar. Abra a pasta novamente com Abrir projeto ou Ctrl+Alt+O. Você também pode desativar Reabrir o último projeto ao iniciar em Preferências.

O pacote não instala

Confirme que o Flatpak está instalado e configurado e que o sistema pode obter o runtime GNOME Platform 51 solicitado pelo pacote. O arquivo .flatpak não inclui dependências; por isso, a instalação pode precisar baixá-las de uma origem Flatpak configurada.

A compilação informa que não encontrou um mecanismo LaTeX

O pacote publicado inclui Tectonic. Se estiver usando uma compilação instalada de outra forma, o Ovenbird também procura latexmk e pdflatex. A primeira compilação com Tectonic pode precisar baixar arquivos de suporte.

O modo Visual não abre o documento

Use o modo Visual em um arquivo .tex que contenha \begin{document} e \end{document}. Para trabalhar com macros ou estruturas que não são representadas nesse modo, volte ao modo Código.

A bibliografia não compila ou a citação não é inserida

Salve o documento LaTeX antes de inserir uma citação. Em erros de bibliografia, confira a mensagem de compilação e se o mecanismo necessário está disponível: documentos que usam BibTeX precisam desse suporte; documentos com biblatex podem precisar de Biber, latexmk ou Tectonic.

Se o problema continuar, registre o sistema utilizado, o passo que falhou e a mensagem exibida no formulário de problemas do projeto.
